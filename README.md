# IT207 AI-Assisted Programming Workshop

## Overview

This project was completed as part of the IT207 AI-Assisted Programming Workshop.

## Commands Implemented

- `mygrep.js` - searches a file for lines containing a specific pattern.
- `myhead.js` - displays the first 10 lines of a file.

## Testing

I tested the programs using a `server.log` file. I tested `mygrep.js` with `INFO` and `ERROR` patterns and tested `myhead.js` by displaying the first 10 lines.

## AI Assistance

I used AI to help understand the programming concepts, debug errors, and create test cases. I verified the suggestions by running and testing the code myself.
